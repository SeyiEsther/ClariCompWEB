How to make carbon reporting audit-friendly

A number and a defensible number are not the same thing. The number is the figure on the front of your report. The defensible number is the same figure, plus the workings that show how you arrived at it. Auditors verify the second one. This is how to build it.

The difference between a number and a defensible number

Every SECR filing produces a number. The Streamlined Energy and Carbon Report itself just needs the total. But the Director who signs the filing has, by signing, asserted that the number is materially correct. The auditor's job is to test that assertion.

If the auditor can reproduce, for any individual row, the journey from input data to emission figure - distance method, factor reference, multiplication, rounding - the assertion holds. If they cannot, the assertion is, technically, unsupported. The number is the same in both cases. Only one of them is defensible.

What the formula trail looks like

A formula trail is a per-row record of the inputs and the operations applied to them. For one row of a ClariComp report it looks like this:

// ROW 1,247 · LHR → DUB · 02 Sep 2024
// M. Aldridge · short-haul · economy

d  = 463.218 km   (Haversine GC)
f  = 0.151378     (DEFRA 2025 T5 · BT-AIR-SH-E)
e  = d × f
e  = 70.1255 kgCO₂e

// SIGNED · 14 Apr 2026 · 03:12 UTC
// SHA256 · 4a2e…f81c

Five lines. Origin, destination, distance and method, factor and reference, multiplication, result. The row hash at the bottom is a tamper detector - if anyone alters the row after signing, the hash changes, and the change is visible.

Three hundred rows of this is a thirty-page appendix. The auditor does not read all thirty pages. They sample. The point is that any row they pick can be reproduced.

How to respond to an auditor query

The most common auditor question on Scope 3.6 is some version of "where did this row's number come from?". Without a formula trail, the answer is necessarily reconstructive - you go back to the spreadsheet, re-derive the distance, look up the factor, and explain what you did. That conversation takes an hour. The auditor bills for the hour. You spend the day before re-deriving.

With a formula trail, the answer is "Appendix C, row 1,247." The auditor reads the five lines, ticks the row, and moves on. The conversation takes ninety seconds.

The cheapest way to manage audit cost is to make the audit boring.

Three habits that compound

1. Stamp the factor set on the row

Not on the report cover. On every row. If your factor table is updated mid-year, you want each calculation to record which version of the table produced it. ClariComp does this by default.

2. Carry precision through; round only at the end

If you round each row to three decimal places of kilograms and then aggregate, you accumulate rounding error proportional to row count. Carry six decimal places through the multiplication. Round once, on the published total.

3. Make assumptions explicit, not invisible

An auditor's instinct, on seeing a clean number, is to look for the assumptions that produced it. If the assumptions are stated openly on each row ("class inferred as economy"), the assumption itself becomes the auditable artefact and the conversation is short. If the assumptions are buried in a methodology paragraph, the auditor has to find them.

What this changes about your audit

An audit-friendly Scope 3.6 number does not eliminate the audit. It changes the shape of the conversation from "explain this" to "confirm this". The first conversation is open-ended and expensive. The second is structured and cheap. Compliance Pro is built around the second.
