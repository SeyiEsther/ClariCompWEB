How it works

From a spreadsheet to a signed report - in six steps.

Every step is self-serve. The product runs in the browser. The only conversation you'll have with ClariComp is the one you choose to have.

Step 01 · UPLOAD

Drop in last year's travel spreadsheet.

ClariComp accepts CSV and XLSX, any column order. The header-matching step happens automatically: trip_date, from_address, to_address, transport_mode, user_name. Distance is computed if missing.

Files over 50 MB or with mixed reporting periods are rejected at the door. ClariComp only accepts last-year data - this is intentional, and explained on the methodology page.

Step 02 · VALIDATE

ClariComp tells you what's missing - before processing.

Required columns are checked first. Completeness is scored per row. If 12% of your trips are missing destinations, you'll see that before a single emission is calculated.

Step 03 · COMPUTE

Distance + factor + multiplication. Visible for every row.

Flights run through Haversine Great Circle. Road and rail run through Distance Matrix. The DEFRA 2025 factor is selected from Table 5 by mode, fuel and class - to six decimal places.

// Haversine Great Circle
d = 2r · asin(√(sin²(Δφ/2) + cos φ₁ · cos φ₂ · sin²(Δλ/2)))

// DEFRA 2025 Table 5 · row lookup
f = passenger.air.short_haul.economy = 0.151378 kgCO₂e/pkm

// Emission
e = d × f
Step 04 · REVIEW

A preview dashboard - not a sales pitch.

Total tonnes. Breakdown by mode. Top-five hottest routes. Data quality score. Tender-readiness rating. Preview PDF download - clearly labelled as indicative.

The preview is the same calculation engine as the paid product. The difference is what you can do with the output, not the integrity of the numbers.

Step 05 · SIGN

Director signature, public verification URL, factor-set stamp.

Compliance Pro generates the signature block and the immutable URL your tender submission can point to. The factor-set version is stamped into the document and into every row - so an auditor checking your file in 2027 can see exactly which DEFRA table produced which number.

Step 06 · EXPORT

Download or generate your report.

There are two outputs. The indicative preview PDF is free, generated on every upload, and clearly labelled as such. The Compliance Pro output is the full SECR annual report and the PPN 06/21 Carbon Reduction Plan, with the formula trail appendix and the verification URL.
